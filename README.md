# PortShare Desktop

The official cross-platform desktop client for [PortShare](https://portshare.kexoz.dev) by Kexoz Labs.

PortShare Desktop provides a modern graphical interface to monitor, manage, and share your local ports and tunnels with a single click.

## Features

- **One-Click Tunnels:** Start HTTP and TCP tunnels directly from your system tray or app dashboard.
- **Traffic Inspector:** Real-time request inspector, status codes, latency graphs, and headers preview.
- **Custom Domains:** Reserve and route traffic to custom subdomains.
- **Cross-Platform:** Available for macOS, Windows, and Linux.

## Tech Stack

- **Framework:** Electron Forge + TypeScript
- **Frontend:** React + Vite + TailwindCSS
- **Core Engine:** PortShare CLI binary integration

## Development

```bash
# Install root dependencies
npm install

# Start development mode
npm run dev
```
